One image summing up the world's news of Monday 23 November 2026: 36 verified
stories across 7 regions — COP31 ending with no deal in Antalya, all three
objects over Poland confirmed as Russian Kh-101 missiles, 128 nations agreeing
to draft killer-robot rules by 2028, and 33 more stories from every region.

The entry is a single 1024×1024 newspaper front page: a giant dated masthead,
the three biggest headlines, a six-number stat strip, a UTC timeline, a region
bar, 13 illustrated stories (3 leads + 10 secondaries), a numbered world map,
a numbered list of 23 more stories, a red DATE CHECK box naming what was left
out on purpose, and a full source list with a certainty legend.

`main.py` (Python 3, standard library only) copies the bundled `entry.png` to
the output directory, byte for byte, so both grader runs write identical output.
